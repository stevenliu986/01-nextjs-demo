# Phase 1：学习 App Router
Analyze the App Router structure.

Do not modify files.

Explain:

1. Which folders are route groups
2. Which folders create URL segments
3. Which layouts apply to which routes
4. How nested layouts work
5. How loading.tsx works if present
6. How error.tsx works if present
7. How not-found.tsx works if present
8. Which pages are Server Components
9. Which pages are Client Components

Then create a route table:

File → URL → Layout → Server/Client
