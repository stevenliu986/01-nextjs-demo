# 用户搜索与筛选功能需求

## 1. 功能概述

为用户列表提供搜索、筛选、排序及重置功能。所有筛选条件支持组合使用，并根据当前条件实时更新用户列表及结果统计。

------------------------------------------------------------------------

## 2. 功能需求

### 2.1 按用户名搜索

-   提供用户名搜索输入框。
-   用户输入用户名后，根据用户名进行匹配。
-   支持与其他筛选条件组合使用。
-   搜索结果仅显示符合当前用户名条件的用户。

### 2.2 按性别筛选

-   提供性别下拉选择框。
-   性别选项至少包括：
    -   全部
    -   男
    -   女
-   默认选择"全部"。
-   支持与用户名、年龄区间及年龄排序组合使用。

### 2.3 按年龄区间筛选

提供两个输入框：

-   最小年龄
-   最大年龄

要求：

-   最小年龄和最大年龄均为可选条件。
-   只填写最小年龄时，筛选年龄大于或等于最小年龄的用户。
-   只填写最大年龄时，筛选年龄小于或等于最大年龄的用户。
-   同时填写时，筛选年龄处于最小年龄和最大年龄之间的用户。
-   最小年龄不能大于最大年龄。
-   年龄输入应限制为有效的非负整数。

### 2.4 按年龄排序

-   提供年龄排序功能。
-   支持：
    -   年龄从小到大
    -   年龄从大到小
-   默认不进行年龄排序。
-   排序可与用户名、性别及年龄区间筛选组合使用。

### 2.5 组合筛选

用户名、性别、年龄区间及年龄排序需要支持组合使用。

例如：

> 搜索用户名为 `John`，性别选择"男"，年龄范围设置为
> `20-30`，并按照年龄从小到大排序。

最终列表应同时满足：

1.  用户名符合搜索条件；
2.  性别符合筛选条件；
3.  年龄在指定区间内；
4.  按指定年龄顺序排序。

所有条件同时生效。

------------------------------------------------------------------------

## 3. 结果统计

-   在用户列表上方显示当前筛选结果数量。
-   显示格式：

``` text
共 N 位用户
```

例如：

``` text
共 12 位用户
```

-   `N` 应根据当前所有筛选条件动态计算。
-   当没有符合条件的用户时显示：

``` text
共 0 位用户
```

并显示适当的空结果提示。

------------------------------------------------------------------------

## 4. 重置功能

提供"重置"按钮，用于清空所有搜索及筛选条件。

点击"重置"后：

-   用户名搜索框清空；
-   性别恢复为"全部"；
-   最小年龄清空；
-   最大年龄清空；
-   年龄排序恢复为默认状态；
-   用户列表恢复显示全部用户；
-   结果统计同步更新。

## 6. 验证规则

  条件       规则
  ---------- --------------------------------
  用户名     可为空；为空时不进行用户名筛选
  性别       默认"全部"
  最小年龄   可为空；必须为有效非负整数
  最大年龄   可为空；必须为有效非负整数
  年龄区间   最小年龄不能大于最大年龄
  年龄排序   默认不排序，可选择升序或降序

当年龄区间输入无效时，应给予用户明确的错误提示，并阻止无效条件生效。

------------------------------------------------------------------------

## 7. 功能验收标准

### 用户名搜索

-   [ ] 可以输入用户名进行搜索。
-   [ ] 搜索结果符合用户名条件。
-   [ ] 可以与其他条件组合。

### 性别筛选

-   [ ] 可以通过下拉框选择性别。
-   [ ] 默认显示全部用户。
-   [ ] 可以与其他条件组合。

### 年龄筛选

-   [ ] 可以只填写最小年龄。
-   [ ] 可以只填写最大年龄。
-   [ ] 可以同时填写最小和最大年龄。
-   [ ] 无效年龄范围能够被正确提示。

### 年龄排序

-   [ ] 支持年龄升序。
-   [ ] 支持年龄降序。
-   [ ] 默认不排序。

### 组合筛选

-   [ ] 用户名 + 性别可以组合。
-   [ ] 用户名 + 年龄可以组合。
-   [ ] 性别 + 年龄可以组合。
-   [ ] 用户名 + 性别 + 年龄可以组合。
-   [ ] 所有筛选条件可以同时生效。
-   [ ] 排序可以与所有筛选条件组合。

### 结果统计

-   [ ] 列表上方显示当前结果数量。
-   [ ] 筛选条件变化后数量同步更新。
-   [ ] 无结果时显示 `共 0 位用户`。

### 重置

-   [ ] 点击重置后所有条件清空/恢复默认值。
-   [ ] 用户列表恢复为全部用户。
-   [ ] 结果统计恢复为全部用户数量。
